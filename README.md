# Binary Linear [2k, k, k]-Codes

This repository contains the report for a group project exploring the existence and properties of binary linear [2k, k, k]-codes.

The project examines the construction of these codes for small values of k and uses the Griesmer bound to investigate the conditions under which such codes can exist.

## Topics

- Coding theory
- Binary linear codes
- Generator matrices
- Griesmer bound
- Error-correcting codes
